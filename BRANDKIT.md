# Villum Brand Kit

## Brand idea

Villum is a calm, practical archive for the people who run fantasy campaigns. The dragon crest protects a **d20**, making the mark immediately useful for D&D while avoiding a generic dragon illustration. The small gold spark preserves the spirit of the former `✧ villum` mark.

## Logo files

- `static/brand/logo-mark.svg` — primary square crest for app icons and compact placements.
- `static/brand/logo-lockup.svg` — horizontal crest, wordmark, and descriptor.
- `static/brand/logo-mark-mono.svg` — single-color version for stamps, embossing, and constrained backgrounds.

Use the full lockup when the Villum name is not already visible. Use the mark alone at sizes below 120px. Do not stretch, rotate, recolor, add effects, or place text inside the clear space around the mark. Keep clear space equal to the height of the gold spark on every side.

## Color palette

| Name | Hex | Use |
| --- | --- | --- |
| Oxblood | `#8B0000` | Primary brand color and wordmark |
| Deep Oxblood | `#5C0000` | Contrast depth and dark surfaces |
| Antique Gold | `#B8963E` | d20 linework, accents, highlights |
| Gold Light | `#D4B96A` | Decorative spark and light accents |
| Parchment | `#F4EBDD` | Light logo field and content surfaces |
| Ink | `#1A0F0A` | Dark mode background and text |

For readable text, use Oxblood or Ink on Parchment. Gold is an accent, not body text; use a darker gold or Ink for small text.

## Typography

- **Display:** Playfair Display, with Georgia as fallback.
- **Body:** Vollkorn, with Georgia/Times as fallback.
- Set the wordmark in lowercase. The lowercase form keeps Villum approachable and matches the product's existing voice.

## Minimum sizes

- Mark: 24px digital / 10mm print.
- Lockup: 180px digital / 45mm print.
- At smaller sizes, use the mark only and never attempt to reproduce the descriptor.

## Accessibility and exports

The SVGs include accessible titles and descriptions. Supply meaningful `alt` text when the logo conveys identity (`Villum`); use an empty alt attribute when it is purely decorative beside a visible name. Prefer SVG for responsive UI. The PWA manifest uses the square crest as its scalable icon.
